# 貓咪叫聲

照檔名放進這個資料夾，App 會自動使用（`.m4a` 或 `.mp3`）。沒有檔案時用 Web Audio 合成喵聲。

叫聲只有 Lv.1 有，每過一關一段，共 33 段：`<章節 key>-<兩位數關卡>.m4a`

| 章節 | 檔名 |
| --- | --- |
| 第一章・指西 | `west-01.m4a` ~ `west-10.m4a` |
| 第二章・指北 | `north-01.m4a` ~ `north-10.m4a` |
| 第三章・指南 | `south-01.m4a` ~ `south-10.m4a` |
| 終章・鴻小兵 | `hong-01.m4a` ~ `hong-03.m4a` |

終極大獎「老子弄不到槍」的槍聲：`gun.m4a`（或 `gun.mp3`），沒有就用合成槍聲。

放好後把 `sw.js` 的 `CACHE_VERSION` 加 1，離線快取才會更新。
