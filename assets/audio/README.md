# 貓咪叫聲

**每過一關得到該章貓咪的 1 段叫聲**。用「章節 key＋兩位數關卡」命名放進本資料夾即可：

| 章節 | 檔名 | 對應「貓貓打氣」按鈕 |
| --- | --- | --- |
| 第一章・指西 | `west-01.m4a` ~ `west-15.m4a` | 指西 |
| 第二章・指北 | `north-01.m4a` ~ `north-15.m4a` | 指北 |
| 第三章・指南 | `south-01.m4a` ~ `south-15.m4a` | 指南 |
| 終章・鴻小兵 | `hong-01.m4a` ~ `hong-03.m4a` | 鴻小兵 |

- 支援 `.m4a` 或 `.mp3`（先找 `.m4a`）。iPhone 錄音 App 匯出的 m4a 可直接用。
- 建議 1~3 秒、單檔 100KB 以內。
- 想用其他檔名，在 `js/config.js` 的 `media` 填路徑，例如 `'west-01': { sound: 'assets/audio/mochi.m4a' }`。
- 沒放音檔時，會用 Web Audio 合成喵聲（每關音高不同，聽得出有在換）。
- 「貓貓打氣」按鈕可以一直按，每按一次就從該章**已解鎖**的叫聲中隨機挑一段（不會連續重複）；過幾關就有幾種聲音。
- 終極獎勵的聲音填在 `config.js` 的 `ultimateReward.sound`。
- 放好後請把 `sw.js` 的 `CACHE_VERSION` 加 1，離線快取才會更新。
