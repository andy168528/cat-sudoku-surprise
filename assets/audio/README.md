# 貓咪叫聲

每個收藏都有一段叫聲。用收藏 `id` 命名放進本資料夾即可：

| 章節 | 檔名 | 對應「貓貓打氣」按鈕 |
| --- | --- | --- |
| 第一章・指西 | `west-1.m4a` ~ `west-4.m4a` | 指西 |
| 第二章・指北 | `north-1.m4a` ~ `north-4.m4a` | 指北 |
| 終章・指南 | `south-1.m4a` ~ `south-4.m4a` | 指南 |

- 支援 `.m4a` 或 `.mp3`（先找 `.m4a`）。iPhone 錄音 App 匯出的 m4a 可直接用。
- 建議 1~3 秒、單檔 100KB 以內。
- 想用其他檔名，可在 `config.js` 該收藏的 `sound` 欄位填路徑。
- 沒放音檔時，會用 Web Audio 合成喵聲（每隻貓音高 `pitch` 不同）。
- 「貓貓打氣」按鈕會在該章**已解鎖**的叫聲間輪流播放；該章還沒解鎖任何收藏時按鈕是鎖住的。
- 放好後請把 `sw.js` 的 `CACHE_VERSION` 加 1，離線快取才會更新。
